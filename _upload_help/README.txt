Hidden files (.github, .gitignore) often do not upload from a phone/browser. Do NOT drag them.
Create them directly on GitHub instead (Add file -> Create new file):
  1) name: .github/workflows/build.yml   -> paste the text of _upload_help/build.yml
  2) name: .gitignore                    -> paste the text of _upload_help/gitignore.txt
After that you can delete this _upload_help folder from the repo.
